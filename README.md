# PDF 整理工具

在瀏覽器裡合併、排序、刪除、複製、旋轉 PDF 頁面，然後匯出成新的 PDF。
所有處理都在你自己的電腦上進行，檔案不會上傳到任何伺服器。

**線上使用：** https://philko2017.github.io/pdf-organizer/

## 功能

- **合併**：一次加入多個 PDF（拖曳或點「加入 PDF」），所有頁面依序排在一起
- **調整順序**：拖曳頁面縮圖；多選後拖曳可整批移動
- **刪除／複製／旋轉頁面**
- **復原**：`Ctrl/⌘ + Z`
- **編輯超連結**（雙擊頁面）：在頁面上拖曳畫出不可見的方框（同 Acrobat「不可見的矩形」），可連到內部頁面或外部網址／Email
  - 已有的連結會標示出來，可移動、調整大小、修改目標或刪除
  - 可選擇顯示框線（顏色、粗細）與點選時的效果
  - 內部連結記住的是「哪一頁」，之後調整頁面順序也會自動跟著走
- **保留內部超連結**：例如封面目錄連到內頁的連結，匯出後會自動對應到新頁碼
  - 連結目標頁被刪除或有多個複本時，匯出前會跳出視窗請你選擇目標頁（可指向替換頁）或移除連結
  - 匯出後會重新開啟檔案，逐一驗證每個連結的範圍、目標頁與網址都正確

## 離線使用（Windows / macOS）

1. 下載這個儲存庫（綠色 **Code** 按鈕 → **Download ZIP**）並解壓縮
2. 雙擊 `PDF整理工具.html`，用 Chrome、Edge、Safari 或 Firefox 開啟

請保留整個資料夾，`lib/` 裡是工具需要的函式庫，只複製 HTML 檔會無法使用。

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| 點選 / `Ctrl/⌘`＋點選 / `Shift`＋點選 | 單選 / 多選 / 範圍選取 |
| `Delete` | 刪除選取頁面 |
| `Ctrl/⌘ + D` | 複製選取頁面 |
| `Ctrl/⌘ + A` | 全選 |
| `Ctrl/⌘ + Z` | 復原 |

## 限制

- 有密碼保護的 PDF 無法載入
- PDF 左側的書籤（目錄）匯出時不會保留
